## Observed Bottlenecks

No runtime bottlenecks have been observed yet because the suite has not been executed.

Pre-run implementation risk:

- The prompt-mandated `TARGET_URL=http://backend:5000/chatHub` does not match the current app, which exposes `http://backend:8080/hubs/chat` and `http://backend:8080/hubs/presence`.
- `ChatHub` currently broadcasts to `room:{roomId}` groups, but the implemented chat hub has no `JoinRoom` method. The load test will still invoke real `SendMessage`, but message-delivery success may fail until chat WebSocket connections can join room groups.
